Footbook

Book stadiums with a simple, clear interface.

This is a lightweight frontend starter for the Footbook project. It gives you a clean homepage now and leaves room for future pages like authentication, stadium listings, and booking management.

What this app will do

  • Show available stadiums and their details.
  • Let users create and manage bookings.
  • Support login and role-based access later.

Current status

The page is intentionally simple: plain HTML, a small amount of CSS, and responsive layout behavior without any framework code.

Next steps

Once you are ready, this page can be connected to the backend API and expanded into separate screens for stadium search, booking flow, and account management.
